IIoT and Image Processing-Based Surface Defect Detection and Automatic Product Rejection System

A student-built prototype exploring how computer vision can help identify visible defects on steel surfaces and support more consistent inspection.

01 · The project

A practical question, explored with vision.

Steel surface inspection is a natural fit for machine vision. This project demonstrates an image-based approach and gives users a place to review model-assisted results.

01

Inspect the image

Analyse a surface photo and highlight regions that may need a closer look.

02

Combine two approaches

Use learned defect detection alongside anomaly analysis to examine both known and unusual patterns.

03

Explore industrial potential

Show how machine vision and IIoT concepts could contribute to repeatable manufacturing checks.

02 · Under the hood

Tools for seeing more.

The current software prototype runs as a web application. Models process captured or uploaded images on the server.

Detection

YOLO

Localizes learned defect categories with bounding boxes and confidence scores.

Anomaly analysis

PatchCore

Highlights visual patterns that appear unusual to the model, including through anomaly maps.

Image input

Camera & uploads

Capture an image on a supported phone browser or select up to six image files.

Application

Results dashboard

Review detections, confidence values, heatmaps and a batch summary in the testing app.

Connected systems

IIoT direction

A starting point for future device monitoring, result logging and system integration.

Future work

Rejection mechanism

Controller and actuator integration can follow once detection timing and decision logic are validated.

A note on validationA PASS result does not prove a product is defect-free. Thresholds need calibration against labelled validation images, and any physical rejection system requires separate testing and safety controls.
03 · The process

From surface to review.

A straightforward workflow for demonstrating the current image-inspection prototype.

1

Acquire an image

Capture a photo on a supported phone browser or upload up to six images.

2

Run model inference

YOLO searches for known classes while PatchCore evaluates unusual visual patterns.

3

Review the outputs

Examine bounding boxes, confidence scores, anomaly heatmaps and the batch summary.

4

Validate the decision

Compare predictions with labelled ground truth and calibrate thresholds before acting on results.
