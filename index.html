01 · Project overview

What are we building?

This project explores an AI-assisted workflow for inspecting visible steel-surface defects. This website explains the project and links to the separate testing application.

🎯

Objective

Build a prototype that analyses surface images, highlights suspicious regions and presents a per-image inspection result.

🔍

Defect identification

Use YOLO for known defect localization and PatchCore anomaly maps to help reveal unusual regions.

🏭

Industrial relevance

Demonstrate how machine vision and IIoT concepts can support repeatable quality checks in manufacturing.

02 · Technologies

Technology stack

The current software prototype runs in a web application; the AI models process captured or uploaded images on the server.

🧠

YOLO

Localizes learned defect categories using bounding boxes and confidence scores.

🌡️

PatchCore

Performs anomaly detection and can create a heatmap of regions that look unusual to the model.

📷

Image acquisition

Capture a photo with a supported phone browser or select up to six image files.

🌐

IIoT concept

Provides a foundation for future connected-device monitoring, result logging and integration.

📊

Results dashboard

Displays detections, confidence values, anomaly heatmaps and a batch summary.

⚙️

Future rejection mechanism

A controller and actuator can be integrated after detection logic and timing are validated safely.

Validation note: A PASS result does not prove a product is defect-free. The PatchCore threshold needs calibration using labelled validation images. Physical rejection requires separate testing and safety controls.
03 · Inspection workflow

From image to result

A clear workflow for demonstrating the current software prototype.

Acquire image

Capture a photo on a supported phone browser or upload up to six images.

Run AI inference

YOLO searches for known classes while PatchCore evaluates unusual visual patterns.

Review outputs

Inspect boxes, confidence scores, anomaly heatmaps and the batch summary.

Validate decision

Compare predictions with labelled ground truth and calibrate thresholds before rejection decisions.

System block flow

Product surface→Camera / image→AI models
Detection + anomaly results→Decision logic→Review / future rejection

The current app demonstrates image-based inspection. Describe physical automatic rejection as planned integration unless the mechanism has been built and tested.
